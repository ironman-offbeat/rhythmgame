# NEON PULSE — Custom Rhythm Pattern Studio

카메라·음악 없이 브라우저에서 원을 눌렀다가 떼는 타이밍을 시험할 수 있는 네온 리듬게임입니다.

## 실행

Production: https://rhythmgame-xi.vercel.app

GitHub `main`과 연결된 Vercel의 자동 배포를 사용합니다.

Node.js 22.12 이상:

```bash
npm install
npm run test
npm run typecheck
npm run build
npm run dev
```

## 플레이 모드

### 일반 모드

- 1~16박 또는 기존 16분음표(0.25박) 간격으로 원이 반복 등장합니다.
- BPM 60~180, 축소 시간 1.2~2.2초, 판정 띠 두께 20~36px 설정 가능.
- 점선 띠 안에서 눌렀다가 벗어나기 전에 떼면 GOOD(+1점), 그렇지 않으면 BAD.
- 마우스, 터치, 스페이스바 입력 지원.

### 커스텀 패턴 제작 모드

1. 화면 상단에서 **커스텀**을 선택합니다.
2. 화면 중앙을 반복 클릭해 원을 연속 추가하거나, 아래 **16박 타임라인**에서 원하는 박자를 클릭해 추가/삭제합니다.
3. **1박 보기**와 **1/4박 보기**를 전환하면 16분음표 위치까지 배치할 수 있습니다.
4. **+16박 구간 추가**로 패턴 길이를 확장할 수 있습니다(최대 256박).
5. BPM, 원 생성 간격(1~16박 및 0.25박), 축소 시간, 판정 띠 두께를 설정합니다.
6. **설정한 간격으로 자동 배치** 버튼은 기존 원을 유지한 채 빈 위치에 원을 추가합니다. 박자 간격은 **자동 배치**에 적용되며, 수동 배치한 원의 박자를 이동시키지 않습니다.
7. 패턴 이름을 지정하고 **패턴 저장**을 누르면 이 브라우저의 `localStorage`에 배치된 박자와 모든 설정이 함께 저장됩니다.
8. **저장된 패턴 → 불러오기**로 편집·플레이할 수 있습니다. 저장된 패턴은 별도로 삭제할 수 있습니다.
9. **JSON 내보내기/가져오기**로 다른 기기로 패턴을 이동할 수 있습니다. 가져온 패턴은 다시 **패턴 저장**을 누르면 로컬 저장됩니다.
10. **직접 플레이** 버튼을 누르면 배치된 원만 시간순으로 등장하고 마지막 원이 사라진 뒤 GOOD/BAD/점수 결과가 표시됩니다.

패턴 파일에는 노트 생성 박자를 나타내는 숫자 배열, BPM, 박자 간격, 축소 시간, 판정 띠 두께, 총 박자 길이, 패턴 이름 등이 포함됩니다. JSON은 제한된 형식으로 검증하며, 불러오기 중 기존 저장 패턴을 조용히 덮어쓰지 않습니다.

**저장 주의:** 브라우저별 로컬 데이터입니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 기기에서는 자동 동기화되지 않습니다. 필요한 패턴은 JSON으로 별도 백업하세요.

## 구현 구조

- `src/game/engine.ts` — 반복/커스텀 시간표, GOOD/BAD 판정, 일시정지, 유한 패턴 종료
- `src/game/patterns.ts` — 패턴 파일 검증, 저장 및 불러오기, 박자 그리드 편집 보조 함수
- `src/game/render.ts` — Canvas 기반 원과 네온 판정 이펙트
- `src/App.tsx` — 모드 전환, 편집기 UI, 저장/불러오기, 입력 통합
- `src/styles.css` — PC·모바일 반응형 UI
- `tests/*.test.mjs` — 노트 생성, 판정, 타임라인, 저장 검증 자동 테스트

## 향후 확장

- 음악 재생/BPM 동기화 및 채보 편집기의 오디오 파형은 현재 구현 범위에 포함되지 않습니다.
- 카메라 연동과 신체 동작 인식도 현재 구현 범위에 포함되지 않습니다.
